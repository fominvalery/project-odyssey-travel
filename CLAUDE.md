# Правила работы с проектом

## ОБЯЗАТЕЛЬНО перед любым действием

1. **Сначала объясни — потом делай.** Никогда не вноси изменения без явного подтверждения пользователя ("да", "делай", "ок").

2. **Не фантазируй.** Если не знаешь причину — проверь логи, БД, код. Не выдвигай версии как факты.

3. **Перед изменением данных (БД, файлы S3) — явно предупреди:**
   - Что именно будет изменено или удалено
   - Обратимо ли это действие
   - Дождись подтверждения

4. **После каждого изменения — проверь результат** через логи или запрос к БД. Не считай задачу выполненной без проверки.

5. **Не трогай то, чего не касается задача.** Если задача в файле A — не меняй файл B.

## Деструктивные операции (требуют особой осторожности)

- `migrate_db` — необратимо, всегда показывай SQL перед применением
- Удаление или обнуление данных в БД — всегда уточняй намерение пользователя
- `sync_backend` — деплоит изменения на продакшн, только после проверки кода
