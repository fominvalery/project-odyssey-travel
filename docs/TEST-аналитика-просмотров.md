## Что сделано

### 1. База данных
Создана таблица `object_views` для учёта просмотров карточек объектов.

**Миграция:** `db_migrations/V0037__create_object_views.sql`

Поля: `id, object_id, owner_id, viewer_id, source, ip, user_agent, created_at`
Индексы: по `object_id`, `owner_id`, `created_at`, `(owner_id, created_at)`.

### 2. Бэкенд-функция `analytics`
**Путь:** `backend/analytics/index.py`
**URL:** `https://functions.poehali.dev/a479bc55-9c4c-466a-aaba-c96f3efc444e`

Эндпоинты:
- `POST /` — зафиксировать просмотр (`object_id`, опц. `viewer_id`, `source`)
- `GET /?action=views&ids=...` — счётчики просмотров для списка объектов
- `GET /?user_id=...&period=7|30|90` — метрики дашборда брокера
- `GET /?org_id=...&department_id=...&period=...` — метрики агентства/отдела

Возвращаемые метрики:
- `views`, `leads`, `requests`, `deals`, `objects`, `conversion`
- `activity[]` — посуточная активность за период

Тесты пройдены: **5/5 (100%)**.

### 3. Трекинг просмотров
**Файл:** `src/pages/ObjectDetail.tsx`

Логика:
- Просмотр фиксируется при загрузке карточки объекта.
- Просмотры самого владельца **не считаются**.
- Повторное открытие той же карточки в одной сессии **не плюсует** (через `sessionStorage`).

### 4. Страница «Аналитика»
**Файл:** `src/components/dashboard/DashboardAnalytics.tsx`

Полностью переписан с моков на реальные данные:
- Карточки метрик: Просмотры, Лиды, Заявки, Конверсия, Объекты, Сделки.
- График «Активность за N дней» — настоящие данные по дням.
- Воронка конверсии — на реальных цифрах.
- «Объекты по категориям» — по реальным объектам пользователя.

Подключение в `src/pages/Dashboard.tsx`:
```tsx
<DashboardAnalytics objects={objects} userId={user.id} />
```

### 5. Счётчик просмотров на карточках объектов
**Файлы:**
- `src/components/dashboard/DashboardObjects.tsx` — массовый запрос `?action=views&ids=...`
- `src/components/dashboard/ObjectsGrid.tsx` — прокидывает `viewsByObject` в карточки
- `src/components/dashboard/ObjectCard.tsx` — показывает иконку глаза + число рядом с городом

## Чек-лист тестирования

- [ ] Открыть карточку объекта от чужого пользователя → счётчик растёт

- [ ] Переключатель 7/30/90 дней → данные обновляются
